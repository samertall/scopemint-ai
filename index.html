THE IDEA

AI suggests.
People decide.

ScopeMint reduces ambiguity in service payments. The model never sends money and never edits the price without human review.

01 / MACHINE LEARNINGUnderstand intent.

A trained Multinomial Naive Bayes model categorizes project briefs and powers milestone planning. An optional OpenAI integration enriches explanations.

02 / TRUST BY DESIGNShow the gaps.

Clarity checks highlight undefined revisions, vague scope, deadlines, and open-ended commitments. Proposals stay editable before approval.

03 / PAYPAL SANDBOXApprove, then pay.

PayPal Orders API v2 handles order creation, payer approval, and capture. Merchant credentials stay on the server. Demo simulation is distinctly labeled.

No escrow. No autonomous transfers. No real charges.

Milestones are agreement artifacts, not locked funds. Payments are only available in PayPal's free sandbox when configured. Do not use this prototype for real financial obligations.
